# Sanora Seller Studio MVP

## Run on Windows

1. Install Python 3.11+.
2. Open Command Prompt in this folder.
3. Run:
   python -m venv venv
4. Activate:
   venv\Scripts\activate
5. Install:
   pip install -r requirements.txt
6. Start:
   streamlit run app.py
7. Open http://localhost:8501

This MVP includes:
- Dashboard
- SEO listing generator
- Catalog analyzer
- Image optimizer
- Profit calculator
- Image experiment database
- Product library
- Competitor tracker

The image optimizer creates legitimate composition variants. It does NOT guarantee a Meesho shipping result. Record the actual result shown by Meesho in Image Experiments.
